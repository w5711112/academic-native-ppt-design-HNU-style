# 自动化与人工质量审查门禁 (Quality Gates & Audit Rules)

> **正式发布版本**：**v5.0 Formal Release (2026年9月23日 永久固化正式版)**  
> **门禁总数**：**41 项刚性质量门禁 (QG-01 ~ QG-41)**  
> **审查通过率要求**：**100% (0 Critical / 0 High)**

本文档规定了 `academic-native-ppt-design-HNU-style` 在交付前的刚性质量门禁与自动化审查指标。所有生成的 `.pptx` 文件必须通过本门禁方可交付。

## 二、自动化质量审查脚本 (`audit_hnu_deck.py`)

运行以下命令对生成的 PPTX 执行全量底层 OpenXML 扫描与 COM 双重质量验证：

```bash
python C:\Users\w5711112\.agents\skills\academic-native-ppt-design-HNU-style\scripts\audit_hnu_deck.py --input <path_to_deck.pptx>
```

自动化脚本将扫描：
1. 检查各页是否存在覆盖全屏的大位图；
2. 扫描所有 `a:t` 的父级 `rPr`，若发现 `sz < 1400`（对应 14.0pt），抛出红线阻断错误；
3. 检查正文段落文字字号是否落在 16.0 ~ 20.0 pt 合规区间内；
4. 检查页面大标题字号是否 $\le 28.0\text{ pt}$，封面主标题字数是否 $\le 17$ 字且未超出右边缘；
5. 扫描所有形状坐标，确保没有物体侵入左下角禁区 `X < 280 pt 且 Y > 355 pt`（除校徽印章本身外）；
6. 检查虚假概念黑名单（CycloneDDS、MINCO、18ms、250Hz 等），命中即阻断；
7. 检查内容页真实图片实装数量，若发现空卡片无图片即抛出红线错误；
8. 检查复杂公式页是否存在 DrawingML 14 原生公式树 `<a14:m>`，且检查公式字体颜色是否已显式注入深灰（杜绝隐形）；
9. 检查普通卡片边框，拦截普遍存在的 0.75pt 细线碎框；
10. 检查表格单元格内边距是否为 0 且垂直居中；
11. 检查宽扁图容器宽度，拦截大框套小图导致的死白；
12. 检查环境中是否有未清理的 `__pycache__` 等临时中间文件；
13. 检查同一页内所有正文字号极差是否 $\le 2.0\text{ pt}$，拦截断崖落差；
14. 检查有图页面图片容器展开程度，确保图片为核心视觉重心；
15. 检查各内容卡片垂直空间利用率，断言 $\ge 60\%$ 且 $\le 108\%$，杜绝下半部死白留白（$< 50\%$ 严重空洞拦截）与文字溢出 (QG-20, QG-36)；
16. 检查相邻组件水平间距，断言不超过 18pt，消除三层多重留白叠加 (QG-21)；
17. 检查 assets 目录结构，断言根目录无裸散图片文件，且项目专属子目录必须包含显式 README 声明，资产文件 100% 对应 PPT 实际引用无孤立死图 (QG-22)；
18. 扫描全篇文字是否存在违禁夸大修饰词（彻底消除、无差拍、底噪极限、零失真、绝对优势等）及脱离素材的脑补实体（变电架构、导线绝缘子），核验表格第一列强制水平居中对齐 (QG-23)；
19. 扫描全篇连续纯文字页跨度，断言无连续超过 4 页无视觉元素违规 (QG-28)；
20. 扫描全篇所有用户图片，断言无任何 PowerPoint 原生 `srcRect` 裁切属性 (QG-29)；
21. 扫描各卡片排布，断言同一行卡片具有完全一致的 Top 与 Height，无高低参差锯齿 (QG-30)；
22. 扫描上下排卡片垂直跨度，断言上下排间距严格 $\le 20\text{ pt}$，绝无中间 100~150pt 死白大坑 (QG-31)；
23. 扫描各分点与标题，断言无机械切字导致的残缺标点或断头字（如“导。”等孤立字）流落正文 (QG-32)；
24. 扫描各卡片分点数量，断言高度 $\ge 120\text{ pt}$ 的卡片分点数 $\ge 2$，严禁单薄单句占大框 (QG-35)；
25. 扫描各页显性非中性主题色数量，断言单页显性主题色 $\le 4$ 种，拦截同级流程卡片无脑轮换 5 色彩虹违规；扫描湖大红等深色底托卡片，断言内部文字 100% 设为纯白 (#FFFFFF / bg1)，拦截黑字配红底的不可读缺陷 (QG-34)；
26. 扫描卡片垂直空间利用率，断言底线 $\ge 60\%$，上限 $\le 95\%$（物理溢出阈值 108%）；扫描正文行间距，断言默认落在 18~20pt（紧凑允许 17pt，舒展允许 21~23pt，严禁 < 17pt），且同一页内所有文本框行间距极差 $\le 1.5\text{ pt}$，断言同页行距完全一致 (QG-36)；
27. 扫描卡片与非对称水印区域，断言右侧承接卡片高度严格齐平（$\Delta h = 0$），左下角开阔避让，消除压顶残块 (QG-37)；
28. 扫描页面大标题与卡片技术事实，若标题承诺跨周期或多厂商技术演进，断言卡片必须全面覆盖核心代表性谱系（DeepSeek, GLM, GPT, Gemini, MiMo），拦截过度概括导致的严重失真 (QG-38)；
29. 扫描全篇卡片标题与正文分点，拦截主观人称代词（我、你、他、我们、大家），拦截大厂黑话与伪架构词（壁垒、资产、原子化、沉淀、高频科研方法、自愈闭环、解耦等），拦截空洞 AI 腔套话（不仅.*而且、显著提升、极大地?赋能、里程碑、飞速发展、旨在打造等）及破折号/分号违规，核验工科白描叙述感与要点加粗 (QG-39)；
30. 检查全篇各 Skill 叙事结构与大纲组织，断言每个 Skill 显式前置痛点与动机，且同一 Skill 页面绝对连续聚合，严禁跨 Skill 穿插割裂 (QG-40)；
31. 扫描全篇所有 `<a:t>` 文本节点，拦截裸露未解析的 Markdown 控制字符（`**`、`__`、`##` 等），保障零 Markdown 泄漏 (QG-41)；
32. 检算所有文本框是否超出所属底托背景卡片的底边边界（`top + height <= card.bottom + 2.0 pt`），拦截穿透与压盖事故 (QG-20/QG-30)；
33. 检查行间距低于 18.0 pt 的页面是否存在虚假降级（底托卡片完全能容纳 18.5 pt 时被误降为 17.0 pt）(QG-36)。
